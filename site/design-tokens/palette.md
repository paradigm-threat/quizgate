# QuizGate theme tokens

The four themes share identical semantic CSS variables. Toggle them with `<html data-theme="sunshine">`, `sky`, `twilight`, or `contrast`.

Use `--bg`, `--surface`, `--surface-2`, `--text`, `--muted`, `--primary`, `--primary-hover`, `--primary-text`, `--accent`, `--accent-text`, `--coral`, `--outline`, `--success`, and `--shadow`.

The default style uses sky blue, golden yellow, coral, soft cream and navy. The high-contrast theme uses heavier outlines and visible focus indicators. Avoid relying on color alone when communicating quiz answers.
