# Next.js App Router starter

Copy `app/*` into your Next.js App Router project. Copy `public/*` into its `public/` directory. The `layout.tsx` uses built-in Next.js metadata, OG and icons. Replace the sample `page.tsx` with your own page. Merge the supplied CSS into your existing global stylesheet if you already have one.

The `site.webmanifest` and the default favicon use the **Gate + Question** icon. For an alternate variant replace the public favicon/touch/PWA files with identically named files from `../icon-packs/lock/` or `../icon-packs/open/` and update `/app/icon.png`, `/app/apple-icon.png`, and `/app/favicon.ico`.

This starter is a drop-in template for an EXISTING Next.js project, not a standalone generated Next.js project with package.json.
