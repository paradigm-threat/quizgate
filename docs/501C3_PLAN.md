# Clevertree 501(c)(3) Approach Plan
*Created: 2026-11-19*

## Scope
- **In scope:** Clevertree LLC (Georgia) + QuizGate + Clevertree Chat
- **Out of scope:** MyProblem (do not mention in filing)

## Note — Repo Visibility
All three GitHub repos need to be switched from private to **public**:
- paradigm-threat/quizgate
- paradigm-threat/clevertree-chat
- paradigm-threat/myproblem (public for transparency, even though excluded from filing)

Public docs are what the IRS reads as evidence of purpose. Private repos can't be cited.

## Phase 1 — Strengthen the Educational Record (Weeks 1–4)
1. Publish a public pedagogy doc for QuizGate: learning objectives per curriculum pack, age bands, how the time-earn mechanic reinforces mastery vs. speed-grinding.
2. Add a "Why this exists" / mission statement page to quizgate.app and clevertree.chat that leads with education and accessibility, not product features.
3. Document the no-tracking, no-ads, no-IAP stance publicly (already in README — surface it on the sites).
4. For Clevertree Chat: write a short essay on how standing-debate structure teaches critical thinking and media literacy. Keep it concrete — cite the rules files, the no-sides AI design, the counter-representation defaults.
5. Gather any usage stats, testimonials from parents/teachers, or pilot feedback. Even informal.

## Phase 2 — Entity Structure (Weeks 3–6)
1. Decide: convert Clevertree LLC → nonprofit, or form a new Georgia nonprofit corp that owns/licenses the apps.
   - Conversion is cheaper but messier if there's any commercial history.
   - New entity is cleaner if Clevertree LLC has any revenue or contracts.
2. File Articles of Incorporation with Georgia Secretary of State (nonprofit). ~$100 filing fee.
3. Adopt bylaws. Key provisions: educational mission, no private inurement, dissolution clause (assets to another 501c3 or government).
4. Appoint at least 3 directors (Georgia requires; IRS strongly prefers independent board, not just founder + family).

## Phase 3 — Federal Filing (Weeks 6–10)
1. Get EIN from IRS (free, online, instant).
2. File Form 1023 (or 1023-EZ if eligible — QuizGate's budget is likely under $50K/yr, so 1023-EZ is probably the move; ~$275 vs $600).
3. Form 1023-EZ asks: mission statement, activities, revenue sources. This is where the education-first narrative gets tested.
4. Attach or reference: curriculum docs, mission pages, bylaws, financial projections (donations only, no program fees).

## Phase 4 — Georgia State Registration (parallel with Phase 3)
1. Register with Georgia Department of Agriculture (charitable solicitation) if soliciting donations from GA residents — required once you ask for money.
2. Initial registration fee + annual renewal. Check current amounts; they've changed in recent years.

## Risk Flags to Watch
- Commerciality doctrine: if QuizGate ever adds paid tiers or ads, the exemption is at risk. Keep it clean.
- Private inurement: founder salary must be reasonable and documented (compensation studies, board approval).
- Clevertree Chat's AI: frame it as educational infrastructure (like a library or textbook), never as a product competing with commercial AI chat.
- Don't describe either app as "free with donations welcome" in a way that reads as pay-what-you-want business. Frame donations as grants supporting the educational mission.

## Success Criteria
- 501(c)(3) determination letter received
- Donor gifts become tax-deductible
- Georgia charitable solicitation registered
- Public repos + mission docs live as permanent evidence
